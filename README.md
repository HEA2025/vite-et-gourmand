# Vite & Gourmand

Projet réalisé dans le cadre de l'ECF du titre professionnel
Développeur Web et Web Mobile (DWWM).

## Environnement technique

- Windows
- PHP 8.4
- Symfony 7.4 LTS
- Composer
- MySQL 8.0
- MongoDB Community Server 8.3
- MongoDB Compass
- Node.js
- Git et GitHub
- PhpStorm

## Installation locale

Les instructions complètes d'installation et de lancement du projet
seront ajoutées au fur et à mesure du développement.
